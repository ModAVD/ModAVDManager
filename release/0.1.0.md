# ModAVDManager v0.1.0

这是 ModAVDManager 的第一个独立版本。`ModAVD.exe` 与 `tools/modavd.exe` 和 [ModAVD v0.36.0 包](https://github.com/ModAVD/ModAVD/releases/tag/v0.36.0)中的对应文件逐字节相同：

- `ModAVD.exe`：`3331b658a9f3a000091f4bda6ed13298e11eceee9962c1ce22e1bcfbccc4d65b`
- `tools/modavd.exe`：`90cb0d9ad05b366144202600d38e6d1341a5b9e20b152a7fbe20a220d558723d`

使用 Go 1.26.5、`GOTOOLCHAIN=local`，运行仓库中的 `build.ps1` 可以编出相同字节。单独下载包还包含 Go 许可原文和文件清单；请用附件 `SHA256SUMS.txt` 核对 zip 和解压出的两个 exe，例如在 PowerShell 里运行 `Get-FileHash .\ModAVDManager-0.1.0-win-x64.zip -Algorithm SHA256`。

0.1.0 没有自更新，单独下载的文件需要手动替换。从 0.2.0 起才提供自更新。单独使用时请给 `--root` 或设置 `MODAVD_ROOT`，否则会提示找不到 ModAVD 根目录。不要把单独下载的 zip 解压到 ModAVD 根目录覆盖整包中的文件。
