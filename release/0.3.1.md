# ModAVDManager v0.3.1

- `ModAVD.exe`：`461d538cdd391928cdf29191c7461d694c7856d7d33bf66179996df839ca58df`
- `tools/modavd.exe`：`dbbb6b721d981af7aed2abcb648458120b9ea8277564b534d560fd8852cfe867`

随 ModAVD 0.37.1 进包。下面是相对 v0.3.0 的改动。

## 新增

- 开发、测试用的根目录可以在 `mas-avd.json` 里写 `portBase`，这个根目录的实例就从它起算端口，不再和同一台电脑上别的根目录里同编号的实例抢端口。可以写 20000，或者 1100–65400 之间 100 的整数倍，每个根目录占一段 100 个端口。没写的根目录和以前一样从 20000 起。
  - 设了 `portBase` 的根目录还要配自己的 `adbServerPort`、`scriptAdbServerPort`，不能用 20049、20050。
  - 不要把它加进 AUTO-MAS，AUTO-MAS 不认 `portBase`。
  - 值不合规时，新建、挑编号、开机都拒绝，看状态的命令照常。

  （ModAVD/ModAVD#75，ModAVDManager#39）

## 变更

- 起模拟器时不再用 netsim（关掉 WiFi 包流、蓝牙模拟和 UWB），也就不再连整机共用的 netsimd。以前它一卡住，这台电脑上之后开的模拟器都开不了机。WiFi 改走模拟器自带的那条路，热点照旧叫 AndroidWifi；游戏的网络本来就不走 netsim，不受影响。（ModAVD/ModAVD#82，ModAVDManager#35）
- `modavd update` 和补全组件用同一套代理规则：先看 `HTTPS_PROXY` / `HTTP_PROXY` / `NO_PROXY`；都没设，就用 Windows「Internet 选项」里手动设的代理。以前只在系统里设了代理的电脑上，补全组件能下，从 GitHub 更新却连不上。用自动配置脚本（PAC）的照旧不读，连不上时会提示设 `HTTPS_PROXY`。（ModAVD/ModAVD#78 的代理这一半，ModAVDManager#38）
- 关机（`modavd stop`、管理器的「关机」）：
  - 前台开着应用时，先按 HOME 让它退到后台，等 2 秒让它存数据。
  - 发关机命令前，先把客体的数据写回磁盘。
  - 关机命令换成走安卓框架的正常关机（`svc power shutdown`），应用先收到要关机的通知。以前的命令绕过框架，前台应用来不及保存就被结束。
  - 等安卓关机最多等到第 24 秒，总时限还是 28 秒。
  - 以前等安卓关机超时以后，兜底时数据已经写不回去，结束进程就等于断电。

  （ModAVD/ModAVD#88，ModAVDManager#41）
- 打开管理器时，不会再另外弹出一个完整的 Edge 浏览器窗口：
  - 管理器窗口用的 Edge 不再自动用 Windows 登录的 Microsoft 账户登录，也不同步、不加载扩展。
  - 关掉管理器窗口时，也不会再在后台启动你自己的 Edge。
  - 配置目录换成新的 `%LOCALAPPDATA%\ModAVD\ui-edge2`。
  - Edge 界面不是中文时，不再弹「翻译此页」。

  （ModAVD/ModAVD#90，ModAVDManager#42）
- 显示 / 隐藏模拟器窗口（`modavd window`，AUTO-MAS 静默模式会用）不再按窗口标题找：在实例自己的 qemu 进程里，按 Qt 的窗口类和属主认出主窗口。以前安全关机途中（标题后面多了「正在关机…」）或鼠标被模拟器捕获时，窗口藏不掉。也为以后把模拟器窗口标题改成实例名（ModAVD/ModAVD#58）做准备。（ModAVDManager#43）
- 补全组件和收集问题信息（ModAVD/ModAVD#72，ModAVDManager#45）：
  - 某个镜像回 HTTP 416 时，不再删掉已经下了的部分（`.part`），换下一个镜像接着下；所有镜像都回 416 时，提示删哪个文件再来。
  - 镜像不支持断点续传、回了整个文件时，从头写。
  - 收集问题信息：`live/` 下文件的换行和 adb 输出的一致；Windows 信息（WMI）每一类单独查、单独限时，一类卡住不再连累别的；收集途中按 Ctrl+C 会删掉暂存目录，不留半个 zip。

## 说明

- 旧的配置目录 `%LOCALAPPDATA%\ModAVD\ui-edge` 新版不再用：升级后打开管理器，窗口出来以后在后台把它删掉。
  - 同一台电脑上还开着旧版管理器时先跳过，下次打开再删；删不掉只记日志，不影响打开。
  - 里面是以前同步进去的收藏夹、历史记录和密码的副本，你自己的 Edge 和 Microsoft 账户里的数据不受影响。
  - 退回旧版时，旧版会重新建一个 `ui-edge`。

  （ModAVD/ModAVD#90，ModAVDManager#42）

## 给调用方（AUTO-MAS）

- `protocol` 还是 2，只加了字段：`list`、`check` 的 `--json` 加 `port_base`（实际用的端口段，不合规时是 20000）；`status --json` 加 `serial`、`adb_address`、`ports`。（ModAVDManager#39）
- `stop` 的总时限还是 28 秒，`--json` 的结构不变。走兜底时，发关机命令前那次 sync 成功也算 `synced`。（ModAVDManager#41）
- `window` 的参数和 `--json` 不变，只是找窗口的办法变了。（ModAVDManager#43）
- `modavd --json components fetch` 不带 `--accept-license` 现在一律报 `usage`（退出码 2），在找根目录之前就报。以前根目录组件齐的时候，这条命令会成功。AUTO-MAS 的 avdcli 不调这条命令。（ModAVDManager#45）

## 下载与核对

使用 Go 1.26.5、`GOTOOLCHAIN=local`，运行仓库中的 `build.ps1` 可以编出相同字节。单独下载包还包含 Go 许可原文和文件清单；请用附件 `SHA256SUMS.txt` 核对 zip 和解压出的两个 exe，例如在 PowerShell 里运行 `Get-FileHash .\ModAVDManager-0.3.1-win-x64.zip -Algorithm SHA256`。

单独下载的管理器不会自己更新，新版本要手动替换；ModAVD 包里的那份随 ModAVD 整包一起更新。单独使用时请给 `--root` 或设置 `MODAVD_ROOT`，否则会提示找不到 ModAVD 根目录。不要把单独下载的 zip 解压到 ModAVD 根目录覆盖整包中的文件。

## English

Shipped in ModAVD 0.37.1. Changes since v0.3.0:

### New

- A root folder used for development or testing can set `portBase` in `mas-avd.json`; its instances then count their ports from that number and no longer collide with the same-numbered instances of another root folder on the same computer. Allowed values are 20000, or a multiple of 100 between 1100 and 65400; each root folder takes a block of 100 ports. Root folders without it start at 20000 as before.
  - A root folder with `portBase` also needs its own `adbServerPort` and `scriptAdbServerPort`, not 20049 or 20050.
  - Do not add it to AUTO-MAS, which does not read `portBase`.
  - With an invalid value, create, picking an index and start refuse; the status commands work as before.

  (ModAVD/ModAVD#75, ModAVDManager#39)

### Changes

- Emulators are started without netsim (Wi-Fi packet stream, Bluetooth emulation and UWB off), so they no longer connect to the netsimd that every emulator on the computer shares. Before, once it hung, no emulator started afterwards on that computer could boot. Wi-Fi now takes the emulator's built-in path and the hotspot is still called AndroidWifi; game traffic never went through netsim and is not affected. (ModAVD/ModAVD#82, ModAVDManager#35)
- `modavd update` and component download use the same proxy rules: `HTTPS_PROXY` / `HTTP_PROXY` / `NO_PROXY` first, and if none is set, the proxy set by hand in Windows' Internet Options. Before, on computers with the proxy set only in Windows, components could be downloaded but updating from GitHub could not connect. Proxy auto-config (PAC) is still not read; when the connection fails, the message suggests setting `HTTPS_PROXY`. (the proxy half of ModAVD/ModAVD#78, ModAVDManager#38)
- Shutdown (`modavd stop`, "Shut down" in the manager):
  - If an app is in the foreground, it first presses HOME and waits 2 seconds so the app can save.
  - Before the shutdown command, it writes the guest's data back to disk.
  - The shutdown command is now Android's normal framework shutdown (`svc power shutdown`), so apps are told first. The old command bypassed the framework, and the foreground app was ended before it could save.
  - It waits for Android to shut down until second 24; the total limit is still 28 seconds.
  - Before, once waiting for Android timed out, the fallback could no longer write the data back, and ending the process was the same as pulling the plug.

  (ModAVD/ModAVD#88, ModAVDManager#41)
- Opening the manager no longer pops up a full Edge browser window:
  - The Edge the manager uses no longer signs in automatically with the Microsoft account Windows is signed in with, does not sync and does not load extensions.
  - Closing the manager window no longer starts your own Edge in the background.
  - Its profile folder is the new `%LOCALAPPDATA%\ModAVD\ui-edge2`.
  - When Edge's interface is not in Chinese, it no longer offers to translate the page.

  (ModAVD/ModAVD#90, ModAVDManager#42)
- Showing and hiding the emulator window (`modavd window`, used by AUTO-MAS's silent mode) no longer looks for the window by its title: it picks the main window inside the instance's own qemu process by its Qt window class and owner. Before, the window could not be hidden during a safe shutdown (the title gets a "shutting down…" suffix) or while the emulator had captured the mouse. This also prepares for naming the emulator window after the instance later (ModAVD/ModAVD#58). (ModAVDManager#43)
- Component download and problem info (ModAVD/ModAVD#72, ModAVDManager#45):
  - When a mirror answers HTTP 416, the part already downloaded (`.part`) is no longer deleted; the next mirror continues it. If every mirror answers 416, the message says which file to delete before trying again.
  - When a mirror does not support resuming and sends the whole file, it is written from the start.
  - Problem info: files under `live/` have the same line endings as adb's output; Windows information (WMI) is queried one class at a time, each with its own time limit, so one class hanging no longer takes the others with it; pressing Ctrl+C while collecting removes the staging folder and leaves no half-written zip.

### Notes

- The old profile folder `%LOCALAPPDATA%\ModAVD\ui-edge` is no longer used. After the update, the manager deletes it in the background once its window is open.
  - If an older manager is still open on the same computer, it is skipped and deleted the next time; if it cannot be deleted, that is only logged and does not stop the manager from opening.
  - The folder holds copies of favorites, history and passwords that were synced into it; your own Edge and the data in your Microsoft account are not affected.
  - If you go back to an older version, it creates a new `ui-edge`.

  (ModAVD/ModAVD#90, ModAVDManager#42)

### For callers (AUTO-MAS)

- `protocol` is still 2; only fields were added: `port_base` in the `--json` of `list` and `check` (the port block actually used, 20000 when invalid); `serial`, `adb_address` and `ports` in `status --json`. (ModAVDManager#39)
- The total limit of `stop` is still 28 seconds and its `--json` has the same shape. On the fallback path, a successful sync before the shutdown command also counts as `synced`. (ModAVDManager#41)
- The arguments and `--json` of `window` are unchanged; only the way it finds the window changed. (ModAVDManager#43)
- `modavd --json components fetch` without `--accept-license` now always fails with `usage` (exit code 2), before the root folder is looked up. Before, the same command succeeded when the root folder already had every component. AUTO-MAS's avdcli does not call this command. (ModAVDManager#45)

### Download and verification

Building with Go 1.26.5 and `GOTOOLCHAIN=local` through the repository's `build.ps1` gives the same bytes. The standalone package also holds the Go license text and a file list; check the zip and the two exes with the attached `SHA256SUMS.txt`, for example `Get-FileHash .\ModAVDManager-0.3.1-win-x64.zip -Algorithm SHA256` in PowerShell.

The standalone manager does not update itself; replace it by hand. The copy in the ModAVD package is updated with the whole package. When you use it standalone, pass `--root` or set `MODAVD_ROOT`, or it reports that it cannot find the ModAVD root. Do not extract the standalone zip over the files of a ModAVD root.
