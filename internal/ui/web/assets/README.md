# assets

`icon-16.png`, `icon-32.png`, `icon-48.png`, `icon-256.png` and `modavd.ico` are the ModAVD app icon, copied from
the output of the icon work (`app-icon-*.png`, `modavd.ico`); the emulator's icon is the same image.

These images are not covered by the licence of the ModAVD code; they ship with the manager as its icon only.


`boot-avatar.png` is the brand avatar (transparent background) scaled to 512 px, shown on the boot screen of the screen viewer. It is the same file as `internal/bootscreen/avatar.png`, which the boot screen over the emulator's window draws (a test checks that they are identical); it is made from the brand artwork, not generated.
