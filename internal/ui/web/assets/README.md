# assets

`icon-16.png`, `icon-32.png`, `icon-48.png`, `icon-256.png` and `modavd.ico` are the ModAVD app icon, copied from
the output of the icon work (`app-icon-*.png`, `modavd.ico`); the emulator's icon is the same image.

The icon is fan art of Eyjafjalla from *Arknights*. The character and its design belong to Hypergryph (鹰角网络).
These images are not covered by the licence of the ModAVD code; they ship with the manager as its icon only.
